# Единая сдача двух частей проекта

1. Выполните упражнение `video_student.py` и обе части: `shots/outcome_student.py` (мяч, броски, обучение) и `players/people_student.py` (DeepSORT/Re-ID). Сохраните код и конфигурацию в своём репозитории, запишите commit SHA.
2. Запустите environment, contracts, train и metrics. Сохраните полный вывод, даже если часть метрик не прошла.
3. Создайте MP4 готовыми командами. Дополнительная графика баллов не даёт.
4. Заполните REPORT.md: seed, обучение, таблица last/mean/GRU, DeepSORT/свой IoU-трекер, статистика и тепловые карты, retrieval/unknown, стресс, три ошибки либо сложных случая и ограничения.
5. Передайте преподавателю ссылку/доступ к своему репозиторию и отдельно архив `artifacts/` и `outputs/`. Не коммитьте скачанные данные, веса, видео результатов, виртуальное окружение или чужие решения в общий шаблон.

После фиксации кода/весов преподаватель проводит закрытую проверку. Нельзя подбирать параметры по её ответам. Если используется GitHub Classroom, следуйте ссылке индивидуального задания; изменения отправляйте в свой репозиторий, не PR с решением в общий шаблон.

Сдаётся одна работа: общий commit SHA, один REPORT.md, модели первой части, журнал бросков и треки игроков, оба MP4 и общий отчёт метрик. Одна реализованная часть не является полным выполнением проекта.
