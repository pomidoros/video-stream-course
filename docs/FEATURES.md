# Формат данных и признаки

`data/recordings.json` задаёт split целыми записями, FPS исходника, прямоугольник кольца `[x1,y1,x2,y2]`, пути к CSV, NPZ и аннотациям. NPZ содержит `frame`, `time_s` и матрицу `features[N,70]`. Номер кадра начинается с нуля; время равно frame/FPS. Детекции сохранены каждые 4 исходных кадра, признаки — каждые 8. Изменение этого шага меняет физическую длину окна.

Пусть `w=x2-x1`, `cx=(x1+x2)/2`. Координата x считается относительно cx, y — относительно y1; обе делятся на w. Ось y направлена вниз. В готовом кеше сырая детекция — ball с максимальным confidence среди confidence≥0,2.

| Индекс | Значение |
|---|---|
| 0, 1 | Нормированные x, y центра сырой детекции, ограничены диапазоном −8…8 |
| 2, 3 | Ширина и высота bbox мяча / w |
| 4, 5 | Confidence и флаг наличия сырой детекции |
| 6, 7 | Нормированные x, y причинного трека, ограничены −8…8 |
| 8, 9 | Скорости трека / w, единица 1/с, ограничены −50…50 |
| 10, 11 | Флаги наличия трека и принятого наблюдения в этом кадре |
| 12 | Время после последнего принятого наблюдения / 0,3 с, ограничено 0…1; до первого наблюдения 1 |
| 13 | Confidence трека; 0 при отсутствии |
| 14…69 | Пространственное кодирование сырого центра мяча |

При отсутствии детекции каналы 0…5 равны нулю. При отсутствии трека 6…11 и 13 равны нулю; отличайте пропуск по флагам. Прогноз Калмана между наблюдениями может иметь track_present=1 и track_observed=0.

Для пространственного кодирования используется сетка из 7 узлов x=−3,−2,…,3 и 8 узлов y=−3,−2,…,4. Сначала меняется x, затем y. Значение узла `(gx,gy)` равно `exp(-((x-gx)^2+(y-gy)^2)/(2*0.5^2))*raw_present`. Оно не является меткой попадания. Готовый трек использует только предыдущие наблюдения, не сглаживание всей записи задним числом.

Аннотации содержат список `attempts`: attempt_id, reference_frame, reference_time_s, outcome (`made`, `missed`, `uncertain`), статусы проверки и точность времени. Исходы проверены Максимом 22 сентября 2026; времена reference_time остаются прежними приблизительными отметками. Ручные интервалы не заменяют их в этой версии. Исходы не являются выходом модели. Для обучения исхода используйте только известные исходы. Для оценки событий неизвестный исход не означает отсутствия попытки.

После формирования признаков вычислите mean/std по train, ограничьте std снизу 0,001. Применяйте этот scaler к остальным частям данных; в базовом опыте стандартизованные значения ограничены диапазоном −6…6. Нельзя вычислять нормализацию по полной train+validation-выборке.
