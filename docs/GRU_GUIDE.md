# Как обучаемая модель получает видеоисторию

Каждый шаг содержит 70 чисел, описывающих положение и движение мяча. Окно из 16 шагов имеет форму `[16,70]`, пачка окон — `[batch,16,70]`. Это обучение по признакам видеопотока, а не обучение визуального детектора по пикселям.

Кадровый baseline видит последний шаг. Mean pooling сначала проецирует каждый шаг 70→32 с ReLU, затем усредняет по времени. GRU получает те же проекции по порядку и обновляет скрытое состояние, сохраняя информацию о предыдущих шагах. Последнее скрытое состояние `[batch,32]` преобразуется линейным слоем в один logit. У `nn.GRU(..., batch_first=True)` последний hidden имеет форму `[layers,batch,hidden]`; для одного слоя нужен `hidden[-1]`.

Logit передаётся в `BCEWithLogitsLoss`; целевые значения — float 0/1. Sigmoid применяется после обучения при расчёте вероятности, не перед этой loss-функцией. В каждом шаге обучения: обнулить градиенты, forward, loss, backward, optimizer.step. Для оценки использовать `model.eval()` и `torch.inference_mode()`.

Сначала соберите окна только из train и удалите из бинарного loss окна uncertain. Нормализацию вычислите только по train-кадрам. Не перемешивайте кадры разных видео в одном окне. Можно перемешивать уже собранные train-окна при обучении.

Сравните last / mean / GRU на одинаковых входах и окнах длины 16. Сохраните loss по эпохам, checkpoint и время. Проверьте, что веса изменились после обучения. Дополнительный опыт — 24 шага; это около 3,07 с истории вместо 2,00 с, поскольку признаки доступны примерно 7,49 раза в секунду.

Для `stream_utils.predict_stream` передайте функцию, которая получает одно нормализованное окно, добавляет batch-ось и возвращает `float(sigmoid(logit))`. Она не должна читать будущие кадры или аннотации. Нельзя использовать ответы эвристики вместо правильных исходов для обучения.

`uncertain` в аннотациях — неизвестный правильный ответ. `unknown` в журнале программы — отказ модели/системы, например из-за нехватки истории. Это разные понятия: уверенный ответ программы не устраняет неопределённость разметки.
