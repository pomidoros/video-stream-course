# OpenCV: 1–2 часа, 5 баллов

Возьмите два любых MP4 из players/videos. Проверьте FPS/число кадров/длительность. Покажите разницу между исходной сеткой 19,98 FPS и кешем 9,99 FPS. Обработайте по 2–3 секунды: grayscale, absdiff с порогом, Farneback либо Lucas–Kanade. Сохраните сравнение кадров/маски/потока. Для скорости достаточно resize640×360.

Объясните три вещи: почему разность не является детектором игрока; как свет/фон/перекрытия влияют на результат; почему пиксели за шаг нельзя выдавать за метры в секунду без калибровки. Затем покажите split и баланс исходов основной части. Сложный optical-flow tracker писать не нужно.
