# Часть 2. Игроки и Re-ID

Реализация: [players/people_student.py](../players/people_student.py). **10 из 50 баллов**, ориентир 3–4 часа. Используйте `deep-sort-realtime` с готовыми признаками внешности; обучение детектора и OSNet не требуется.

## Данные

В `players/videos/` — три игровых MP4. В `players/data/` — детекции, признаки OSNet, разметка для оценки и результаты геометрического baseline. Исходные видео имеют частоту 19,98 FPS, кеш — 9,99 FPS. Разделение development/evaluation задано в manifest.

ID локальны внутри записи. Один и тот же номер в разных видео не означает одного человека. Целевые объекты — игроки на площадке; детектор может находить и других людей.

## Что реализовать

1. **`cosine_distances`** — расстояния между признаками запросов и образцов.
2. **`identify_people`** — ближайший образец из gallery или `unknown`, если сходства недостаточно.
3. **`track_with_deepsort`** — адаптер трекера к детекциям и внешним признакам. Обрабатывайте каждый шаг, включая шаги без детекций. Форматы и начальные параметры — в [API](../docs/API.md).

## Что исследовать

- Сравните DeepSORT с готовым геометрическим baseline по IDF1, MOTA, сменам ID, FP и FN.
- Проверьте поведение при пропусках детекций. Готовый запуск убирает наблюдения на шагах `20 ≤ step % 45 < 25`, сохраняя течение времени.
- Оцените Re-ID: gallery строится из первой трети видео, query — из последней. Готовый протокол также исключает одну личность из gallery для контролируемой проверки `unknown`. Сообщите top-1, долю правильно принятых известных и ложные принятия неизвестных.
- Посмотрите видео результата, сформулируйте причину одной из ошибок и **проверьте одно своё улучшение**. Сравните до/после на тех же данных. Способ улучшения выберите сами.

Параметры выбирайте на development, затем фиксируйте для evaluation. Эталонная разметка используется только в оценке и отдельном retrieval-эксперименте. Трекер её не получает. Перенумеровывать предсказания по правильным ID нельзя.

В отчёте нужны таблица результатов и объяснение эксперимента. Рост всех метрик не обязателен. Это малый учебный поднабор: его результаты нельзя выдавать за качество на любых игровых сценах.

Видео с рамками, подписями и карточками создаёт [готовый скрипт](../docs/VISUALIZATION.md).
