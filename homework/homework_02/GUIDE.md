# Установка и запуск

Все команды выполняйте в папке с `homework.py` и `run.py`. Рекомендуется Python 3.11 или 3.12. Нужны CPU и ориентировочно 4 ГБ свободной RAM; запас места для окружения — 3 ГБ. Интернет нужен для установки библиотек и первого скачивания весов.

## 1. Подготовить окружение

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

На Windows вместо первых двух команд используйте `py -m venv .venv` и `.venv\Scripts\Activate.ps1` в PowerShell. После активации команды с `python` одинаковы.

## 2. Дописать функции и проверить

```bash
python -m pytest tests -q
```

В исходном шаблоне одиннадцать проверок завершаются `NotImplementedError`: это ожидаемо. После реализации все должны проходить. Тесты используют маленькую искусственную модель и не скачивают веса.

В русских docstrings четырёх функций описаны входы, выходы и требования к результату. Кадры нумеруются с нуля; у исходного видео и выборки могут быть разные FPS. Способ реализации выберите самостоятельно, опираясь на материал модуля 5.

## 3. Выполнить эксперимент

```bash
python run.py
```

Первый запуск скачивает веса R3D-18 (около 127 МБ) в кеш PyTorch. Последующие используют кеш. Программа работает на CPU и обрабатывает клипы по одному, чтобы ограничить расход памяти. Пока TODO не заполнены, полный запуск завершится ошибкой.

Если преподаватель выдал веса отдельным файлом, можно работать без их скачивания:

```bash
python run.py --weights /путь/к/r3d_18-b3b3357e.pth
```

## 4. Посмотреть результат

В `outputs/` появятся:

| Файл | Что смотреть |
|---|---|
| `predictions.csv` | Шесть строк: два видео × original/shuffled/frozen; top-1, top-3 и оценки классов |
| `clips.csv` | Ответы отдельных клипов до объединения |
| `metrics.json` | Число верных ответов из двух и время обработки |
| `comparison.png` | Оценка правильного класса для трёх вариантов |
| `comparison.mp4` | Три колонки: исходный, перемешанный и замороженный клип с ответами сети |
| `annotated_examples.mp4` | Исходные видео с правильными метками и ответом сети для каждого видео |

Начните с `comparison.mp4`: **ORIGINAL** — исходный порядок, **SHUFFLED** — перестановка, **FROZEN** — повтор кадра. В каждой колонке показан тот самый клип, который был подан сети, его top-1 и оценка правильного класса. Все шесть исходных клипов показаны последовательно; каждый повторён дважды только для удобства просмотра. Модель обрабатывает его один раз.

Таблица `clips.csv` содержит ответы отдельных клипов, совпадающие с подписями сравнительного видео. В `predictions.csv` и на графике показаны ответы после объединения трёх клипов каждого видео — они могут отличаться от ответа одного клипа. `annotated_examples.mp4` показывает полные исходные ролики с такими общими подписями.

По умолчанию `seed=42`, одна воспроизводимая перестановка на клип. Необязательно: для другого порядка запустите `python run.py --seed 7 --output outputs_seed7`. Сохранение или изменение ответа в одном таком опыте не характеризует все возможные перестановки. Это анализ готовых клипов целиком, без поиска временных границ событий.

Заполните `REPORT.md` и отправьте его вместе с `homework.py` и папкой `outputs/`. Веса, окружение и исходные видео повторно прикладывать не нужно.
