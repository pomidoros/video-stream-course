# Домашнее задание 2: «Что узнала видеосеть?»

Изменится ли ответ видеосети, если переставить кадры местами? Вы сравните исходные клипы, те же кадры в случайном порядке и повтор одного кадра. Цель — исследовать влияние временной структуры на ответы готовой модели.

1. Прочитайте [условие](ASSIGNMENT.md) и посмотрите два ролика в `data/`.
2. Установите зависимости по [инструкции запуска](GUIDE.md).
3. Допишите четыре функции в `homework.py`, выполните тесты и запустите `run.py`.
4. Посмотрите полученные видео и график, заполните [короткий отчёт](REPORT.md).

Планируемое время: **90–120 минут**, включая разбор результатов. Нужен обычный компьютер с Python; GPU не требуется. При первом запуске скачиваются готовые веса размером около 127 МБ. Обучение модели не входит в работу.

## Быстрый старт

Из корня репозитория:

```bash
cd homework/homework_02
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

На Windows используйте `py -3.12 -m venv .venv` и `.venv\Scripts\Activate.ps1`. Два исходных видео уже включены в `data/`; информация об источниках — в [data/SOURCES.md](data/SOURCES.md).

После реализации четырёх функций в `homework.py`:

```bash
python -m pytest tests -q
python run.py
```

В чистом шаблоне 11 тестов ожидаемо завершаются `NotImplementedError`. Тесты не скачивают веса и не требуют GPU. Полный эксперимент скачает веса R3D-18 при первом запуске и сохранит видео, график и таблицы в `outputs/`.
