# Происхождение и условия данных

**Видео и GT людей:** TrackID3x3, Kazuhiro Yamada, Li Yin, Qingrui Hu, Ning Ding, Shunsuke Iwashita, Jun Ichikawa, Kiwamu Kotani, Calvin Yeung, Keisuke Fujii (2025). [Проект и условия Dataset](https://github.com/open-starlab/TrackID3x3#dataset), [статья](https://arxiv.org/abs/2503.18282v2), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Согласно разделу Dataset, видео, разметка и промежуточные данные лицензированы CC BY 4.0. Оригинальные MP4 сохранены без изменений; разметка прорежена вдвое, индекс кадров переведён в 0-based, xywh → xyxy. Детекции, эмбеддинги и геометрические треки рассчитаны для курса. Сохраняйте эту атрибуцию при распространении поднабора/своих визуализаций. Авторы исходного набора не утверждали и не проверяли этот учебный проект.

Точные URL, SHA-256 и перечень изменений — DATA_PROVENANCE.json; снимок README — licenses/TrackID3x3-README-source.txt. Код сторонних CAMELTrack/jersey-number-pipeline не включён.

**Числовые потоки бросков:** измерения детектора, признаки движения и ручная разметка Максима по роликам из [Basketball-Score-Detection-ComputerVision](https://github.com/gbikushev/Basketball-Score-Detection-ComputerVision). В комплект входят числовые результаты обработки и собственная разметка, без исходных кадров, аудио, роликов или чужих весов. Явная лицензия исходных роликов в репозитории не найдена; разрешение на их перераспространение не получено. Эти материалы не объявляются CC BY 4.0 и не смешиваются с лицензией TrackID3x3. Для выполнения задания исходные ролики не нужны; не добавляйте их в публикуемый архив на основании этой документации.

**Алгоритмы:** DeepSORT adapter использует deep-sort-realtime (MIT); OSNet-признаки рассчитаны официальной torchreid OSNet x0.25 MSMT17, код MIT. Исходные веса энкодера/детектора не включены. Зависимости устанавливаются отдельно с собственными лицензиями. Информацию о версии и хешах генераторов содержит players/data/manifest.json.

Здесь зафиксировано происхождение конкретных файлов; общей лицензии на все сторонние материалы проекта не заявляется.
