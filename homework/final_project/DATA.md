# Данные: что скачать и куда положить

В Git находятся код и инструкции. Учебные данные скачиваются отдельно.

**Файл:** `cv-video-data-v1.zip` — около 11 МБ, после распаковки около 14 МБ.

**Ссылка на Яндекс Диск:** пока не добавлена преподавателем. После загрузки она будет указана здесь и в `assets.json`.

## Установка

Скачайте ZIP и выполните из корня проекта:

```bash
python scripts/setup_data.py --archive /путь/к/cv-video-data-v1.zip
```

Скрипт проверит архив и разложит данные:

```text
cv-video-final-project/
├── data/              # броски: признаки, детекции и разметка
└── players/
    ├── data/          # игроки: детекции, признаки внешности и разметка
    └── videos/        # игровые MP4
```

Можно распаковать ZIP вручную **в корень проекта**, без дополнительной вложенной папки. Затем проверьте данные:

```bash
python scripts/check.py environment
```

После добавления ссылки также будет доступна команда `python scripts/setup_data.py` без аргументов. Своя ссылка на файл передаётся через `--url`. Повторная установка заменяет файлы подготовленных данных; код студента не затрагивается.

## Веса

Для задания готовые веса скачивать не нужно. Детекции и признаки OSNet уже входят в архив. Свои модели исходов вы обучаете командой `python -m project train`; веса появляются в `artifacts/last.pt`, `mean.pt` и `gru.pt` вместе с параметрами и историей обучения.

Преподавательские веса и закрытые данные не входят в учебный архив. Папки данных, весов и результатов исключены из Git. [Происхождение и условия использования данных](DATA_SOURCES.md).
