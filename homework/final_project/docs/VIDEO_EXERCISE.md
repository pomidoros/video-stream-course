# Видео и движение — 5 баллов

Реализуйте четыре функции в [video_student.py](../video_student.py):

1. `read_frames` — генератор кадров, пропуск кадров с сохранением исходного времени, уменьшение изображения и корректное закрытие видео.
2. `motion_mask` — разность яркости, порог и удаление маленьких связных областей.
3. `dense_flow` — плотный поток Farneback средствами OpenCV.
4. `summarize_motion` — доля движущихся пикселей и медианная скорость по маске с учётом времени между кадрами.

Для чтения дан OpenCV, но цикл обработки нужно написать самостоятельно. Обработайте первые 30 шагов двух игровых MP4. При stride=2 используйте исходные номера 0, 2, 4…; время равно номеру / исходному FPS. Уменьшайте кадры до ширины 640 пикселей.

После реализации:

```bash
python -m project video --output outputs
```

Готовый скрипт создаст `outputs/video/motion.json` и две иллюстрации «кадр / маска / величина потока». Самостоятельно писать отрисовку не требуется.

В отчёте объясните, почему маска движения не равна детектору игрока; что происходит при перекрытии или изменении света; почему скорость в пикселях зависит от масштаба и положения в кадре. Затем покажите split и баланс исходов бросков.

Баллы: чтение и временные метки — 2, маска — 1, поток и сводка — 1, объяснения — 1. Ориентир — 2 часа.
