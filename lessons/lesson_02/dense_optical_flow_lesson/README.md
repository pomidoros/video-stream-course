# Плотный поток Farnebäck

Откройте [lesson.ipynb](lesson.ipynb): готовый Farnebäck, цвет/стрелки, текстура/угол/граница, пирамида, видео и компенсация движения. Собственной реализации плотного потока нет.

[Установка и запуск](../README.md). Окружение общее для трёх папок.

Начните с переноса `(0.5, 0.25)` и scale=1. Для `(12, 6)` используйте scale=16. Mode и scale меняют показ; window_size, levels и iterations — расчёт. В `outputs/` есть готовые ролики. Для пересоздания из этой папки запустите `python run_demo.py`; `python validate.py` проверяет известный перенос и компенсацию.
