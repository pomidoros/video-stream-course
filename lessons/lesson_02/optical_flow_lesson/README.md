# Разреженный Lucas–Kanade

Откройте [lesson.ipynb](lesson.ipynb): OpenCV PyrLK, короткая собственная LK, пара кадров, проверка вперёд–назад и встроенные ролики. Собственная версия делает один линейный шаг без пирамиды и итераций; она предназначена для малого переноса.

[Установка и запуск](../README.md). Окружение общее для трёх папок.

В `outputs/` — сравнения OpenCV L0/L3. Для пересоздания из этой папки запустите `python run_demo.py`; gap меняется в конце скрипта. `python validate.py` проверяет малые переносы собственной версии и готовый OpenCV.

`visuals/lucas-kanade.html` — дополнительный интерактив, открывается в браузере.
